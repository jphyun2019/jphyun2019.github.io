# jphyun2019.github.io

Personal academic site for Jonathan Hyun. Plain HTML and CSS, no build step.

- Edit content in `index.html`, styles in `styles.css`, files in `assets/`.
- Update the "Last updated" line in the footer when you change content.
- Pushing to `main` deploys automatically via GitHub Pages at https://jphyun2019.github.io.
